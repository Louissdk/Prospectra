# Política de privacidade — Prospectra

## Dados tratados

A extensão armazena localmente no perfil do Chrome os dados empresariais coletados pelo usuário: nome, categoria, telefone, endereço comercial, site, e-mails públicos encontrados, avaliação, link do Google Maps e data da coleta.

## Onde os dados ficam

Os leads são guardados em `chrome.storage.local`. Esta versão não envia a base para um servidor do desenvolvedor, não cria conta e não utiliza serviço de analytics.

## Acesso a sites externos

Quando a opção de busca de e-mails está ativada, o Chrome solicita permissão opcional para consultar sites HTTP/HTTPS. A extensão pode ler o HTML público do site da empresa e de até duas páginas internas de contato. As consultas são feitas diretamente do navegador do usuário.

## Compartilhamento

A extensão não compartilha a base com terceiros. Ao exportar CSV ou JSON, o usuário escolhe onde salvar o arquivo. A navegação para um site externo segue a política de privacidade desse site.

## Retenção e exclusão

Os dados permanecem no armazenamento local até serem apagados nas configurações da extensão ou até que os dados da extensão sejam removidos pelo Chrome.

## Segurança

A extensão aceita apenas URLs HTTP/HTTPS e bloqueia endereços locais/privados conhecidos na etapa de enriquecimento. Essa proteção reduz riscos, mas não substitui uma auditoria de segurança de rede completa.

## Contato

Esta versão não possui um canal de suporte ou coleta de dados do usuário pelo desenvolvedor.
